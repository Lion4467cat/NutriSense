# Upstream IEEEtran template files

`bare_conf.tex` and `IEEEtran_HOWTO.pdf` are retained from the unmodified
IEEEtran 1.8b CTAN archive. The original copyright, attribution, and LPPL terms
remain in `bare_conf.tex`; the class and BibTeX style are kept in the parent
directory for the manuscript build. `main.tex` is the project-specific working
scaffold based on the conference starter.

Source: <https://mirrors.ctan.org/macros/latex/contrib/IEEEtran.zip>

CTAN package page: <https://ctan.org/pkg/ieeetran>
