# 01: Cache frozen encoder features for head training

**What to build:** Weight-head training computes the frozen encoder's features once per dataset and reuses them for every epoch (and later, every calibration fold). A full 100-epoch run drops from ~70 minutes (GPU-contended) to a few minutes, with bit-identical training results. The cache is a local, git-ignored artifact.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Training tool accepts a cache location; first run builds it, later runs reuse it
- [ ] A GPU-marked test proves cached-path and live-path training produce identical weights (golden-style, like the existing weight-head load guards)
- [ ] Non-GPU suite stays hermetic and green (the new test is gpu-marked; CI path unaffected)
- [ ] The stale `weight_head_train.json` report artifact gets regenerated by the next real training run (documented staleness cleared — no retrain just for the JSON)
- [ ] Wall-clock improvement recorded (before/after timing on this box)
