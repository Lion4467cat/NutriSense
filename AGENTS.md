# NutriSense — agent instructions

## Package management: uv only
- Always use `uv`, never `pip`.
- Env: `.venv/` (uv-managed, CPython 3.14) at repo root.
- Create: `uv venv --python 3.14 .venv`
- Install: `uv pip install --python .venv/bin/python <pkg>`
- Run API: `.venv/bin/uvicorn main:app`
- System python is PEP 668 locked; `pip install` will fail — do not use `--break-system-packages`.

## Protected files — read before you touch

Rule: never edit a protected path without saying so in the commit message;
the eval lock can only be regenerated by the approved `--write`, and CI's
`check_locked` gate (plus `tests/test_locked_eval.py`) fails on any
unpinned drift. Changing one of these is a decision, not a fix.

| Path | Why protected | How to change it |
| --- | --- | --- |
| `docs/locked_manifest.txt` | the eval lock: SHA-256 pins over eval code, split definition, locked images | only `.venv/bin/python -m tools.check_locked --write` (approved; always show `git diff docs/locked_manifest.txt`) |
| `data/wed_manifest.jsonl` | WED split definition (train/val/test carve, seed 42) | `.venv/bin/python -m tools.build_wed_manifest`, then re-pin |
| `data/wed/test/` | locked test split — chmod'd read-only on disk | deliberately unlock only: `chmod -R u+w data/wed/test`; re-lock with `chmod -R a-w data/wed/test` |
| `pyright.baseline` | the 216-error pyright baseline | `python -m tools.pyright_gate --update` only after fixing real errors — never to hide a new one |
| `ruff.toml` | lint gate is 0 findings via deliberate relaxations | do not add a relaxation to land a change; fix the code |
| `frontend/package.json` deps | `playwright-core` is deliberately absent (`npm i`/`npm uninstall` prunes it) | restore with `npm i --no-save playwright-core` |

Never pinned, by design — the variable under test: `models/weight_head.py`,
`tools/train_weight_head.py`, `data/weight_head_sigma.yaml`,
`data/weight_head.pt`. Model integrity is guarded separately (encoder
checksum + golden MAE, `tests/test_weight_head_load.py`).
