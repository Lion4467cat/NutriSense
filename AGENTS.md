# NutriSense — agent instructions

## Package management: uv only
- Always use `uv`, never `pip`.
- Env: `.venv/` (uv-managed, CPython 3.14) at repo root.
- Create: `uv venv --python 3.14 .venv`
- Install: `uv pip install --python .venv/bin/python <pkg>`
- Run API: `.venv/bin/uvicorn main:app`
- System python is PEP 668 locked; `pip install` will fail — do not use `--break-system-packages`.

## Project state

No real-capture IoU, Dice, or item-detection F1 has been measured; current synthetic tests check overlap partition invariants, not segmentation accuracy. `models/food_classifier.py` uses SigLIP2 over the configured WED classes. The WED crop report is 81.03% top-1 (987/1,218), but 41 of 108 DEV views overlap gallery sources; the 78.03% gallery leave-one-out result on 997 embeddings is also not independent evidence. Treat both as limited crop/gallery diagnostics, not meal accuracy. The current gallery threshold is configured in `data/params_status.yaml`.
- **S3 done**: `models/portion_estimator.py` — grams = anchor-scaled footprint area × mean depth height above base plane. Ring path (band 1.5% inside mask, **select LARGEST plane residuals** — camera-z decreases with height, low-residual picks the top) → ±7% volume vs GT. Table-prior path flagged `vessel_shape_uncertain`. Prior anchor tier: size prior on ellipse minor axis **de-foreshortened by assumed tilt**. Area uses `cm_px² · ((1+cos tilt)/2)² / cos tilt` (mean-side cm/px under-foreshortens — plain `/cos` overcounts 27% at 39°). Returns `sigma_rel` dict only — intervals belong to S4.
- **S3 depth**: `engine/depth.py` — MoGe-2, called with `fov_x` when known; the serving backbones are pinned in `models/model_revisions.py`. The ~1.1% median card-calibration result is from a rendered/synthetic diagnostic, not real-meal depth validation. Prior-tier scale remains unvalidated. Do not use the synthetic figure as a real-capture accuracy claim.
- **S4 done**: `engine/mc.py` (sole interval owner: lognormal grams from `sigma_grams_rel`, recipe-share noise, table sigma from `nutrient_table_sigma_pct`, temperature_scale widens central interval, raw-equivalent diagnostics informational only) + `engine/nutrients.py` (`data/nutrients.yaml`: rice_boiled literature, others assumed).
- **S5 done**: `engine/compliance.py` — P per mandatory nutrient, coverage = product of `coverage_*` params (no-card learned-weight factor 0.90 can reach PASS/FAIL; geometry-prior factor 0.60 cannot), PASS ≥0.9 & C≥0.85 / FAIL ≤0.1 & C≥0.90 / else BORDERLINE, salt advisory only. Hard gates (zoom/day/band → input, out-of-scope dish → classify) live in `engine/gates.py`, consulted once by `analyze()` before assess() scores. **2026-10-11:** no-card plates are scored like any other but always lead their reasons with the `no_reference_card` estimate disclaimer — learned grams get `coverage_estimated_weight` 0.90 (PASS/FAIL reachable), geometry grams keep the 0.60 cap (ADR 0002 + amendment).
- **S6 done**: `engine/pipeline.py` (`analyze(image, day, band, exif, deps)` — deps override segment/classify/depth for tests) + `main.py` `/health` `/menu` `/goals` `/analyze` (multipart file+day+band). - **Multi-item serving path**: recognized, in-scope meals in either mode run the 3×3 detector. Shared mask pixels are partitioned once before per-region portion estimates; repeated food labels can represent distinct servings. The school verdict is produced only when labels and components resolve completely. If structure or labels remain uncertain but a whole-mask numeric estimate is possible, the pipeline returns `ESTIMATED` without a school verdict; actual portion/nutrition failures remain `cannot_verify`. These fallbacks and partition invariants have synthetic regression coverage only; real-mask/meal accuracy has not been measured. Detection accepts at most nine regions. - Kill switch: `.venv/bin/python -m tools.should_stop || exit 0` — MUST be the first command of every loop iteration; exit 1 while `STOP` exists in the repo root (`touch STOP` pauses, `rm STOP` resumes; `STOP` is gitignored)

- OpenCV 5 gotchas: `generateImageMarker` (not generateMarker); `getPerspectiveTransform` needs float32; numpy≥2 has no 2-D `np.cross`.
- Transformers 5 gotchas: load SigLIP2 with `AutoModel` (its config is `model_type: siglip`; `Siglip2Model.from_pretrained` fails shape checks); SigLIP logits = `cos·exp(logit_scale)+logit_bias` (model params); SAM2 points need 4-dim `[image, object, point, xy]` nesting, boxes 3-dim; SAM2 masks come back at 256×256 — resize logits to full res.
- Depth gotchas: install MoGe with `--no-deps` (its pyproject drags gradio/flex-gemm); calibration compares must be meters; `unit_interval`/`interval_90` MC summary key; mc sample key is `protein_g_samples` (matches standards nutrient key).

## Protected files — read before you touch

Rule: never edit a protected path without saying so in the commit message;
the eval lock can only be regenerated by the approved `--write`, and CI's
`check_locked` gate (plus `tests/test_locked_eval.py`) fails on any
unpinned drift. Changing one of these is a decision, not a fix.

| Path | Why protected | How to change it |
| --- | --- | --- |
| `docs/locked_manifest.txt` | the eval lock: SHA-256 pins over eval code, split definition, locked images | only `.venv/bin/python -m tools.check_locked --write` (approved; always show `git diff docs/locked_manifest.txt`) |
| `data/wed_manifest.jsonl` | WED split definition (train/val/test carve, seed 42) | `.venv/bin/python -m tools.build_wed_manifest`, then re-pin |
| `data/wed/test/` | locked test split — chmod'd read-only on disk | deliberately unlock only: `chmod -R u+w data/wed/test`; re-lock with `chmod -R a-w data/wed/test` |
| `pyright.baseline` | the 187-error pyright baseline | `python -m tools.pyright_gate --update` only after fixing real errors — never to hide a new one |
| `ruff.toml` | lint gate is 0 findings via deliberate relaxations | do not add a relaxation to land a change; fix the code |
| `frontend/package.json` deps | `playwright-core` is deliberately absent (`npm i`/`npm uninstall` prunes it) | restore with `npm i --no-save playwright-core` |

Never pinned, by design — the variable under test: `models/weight_head.py`,
`tools/train_weight_head.py`, `data/weight_head_sigma.yaml`,
`data/weight_head.pt`. Model integrity is guarded separately (encoder
checksum + golden MAE, `tests/test_weight_head_load.py`).
